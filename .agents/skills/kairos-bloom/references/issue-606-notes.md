# Kairos — Issue #606 reference analysis

Every asset in the issue was downloaded and inspected one by one (29 stills, 4 motion clips,
frames sampled at 1s / 4s / 7s). Notes below are per asset, then synthesised into rules.

## B. Synthesis — what the user is asking for

The current app is *tasteful but cold*: one blue gradient, white cards, one cobalt accent, no
character, no surprise. The references point to a warmer, more **physical, playful and hopeful**
Kairos:

1. **A world, not a gradient.** Dawn sky → paper → dusk. Grain, soft blooms of colour, light
   leaks. Sky is a stage that changes with the time of day and the user's mood.
2. **Objects, not cards.** Paper notes, frosted folders, sealed envelopes, glossy blooms,
   stickers, torn edges, dashed scrapbook tiles. Slight rotations and overlap.
3. **One hero per screen.** Enormous serif word / number / headline, ghost type behind it.
4. **Colour with feeling.** Butter, coral, rhododendron pink, mint, periwinkle, leaf. One
   saturated object per screen, everything else quiet.
5. **A character.** A bloom mascot with a face — the "moment" that opens. It reacts to saves,
   streaks, empty states, API-key success.
6. **Motion as material.** Sequential bloom, squash-and-stretch, spring stacks, cloud wipes,
   orbit lines, marquee petals, particle halos, countdown ticks. Not just fades.
7. **Personal.** Nepal: rhododendron (national flower, *laligurans*) blooming at dawn in the
   Himalaya; the mark should carry that, plus the user's own "P" seed.
8. **Craft details.** Mono eyebrows, hairline rules, 9–11px labels with 0.08em tracking,
   gradient scrims on photos, status dots, real waveforms, pressed/tactile states.
9. **Share cards as art.** Nature macro / riso / painted / flat-blue type templates, grain
   overlays, serif or pixel type, tiny monogram.
10. **Never a to-do list.** Copy is literary, warm, second person, occasionally funny. No
    productivity chrome, no "tasks", no red badges unless something is truly wrong.

## C. Concrete tokens extracted

- Radii: 12 (chip), 20 (tile), 28 (card), 36–44 (sheet/phone panel), full pills.
- Spacing: 4 grid; 20 side margins; 24–32 card padding; 16 gaps.
- Type: display serif 44–72 / tight; UI sans 15–17; labels 11–13 semibold; eyebrow 10 mono
  uppercase +0.12em.
- Grain: 4–8% monochrome noise, always.
- Shadows: wide, low-opacity, tinted (never pure black), plus inner 1px white rim on glass.
- Motion: 260–420ms springs (damping 0.7–0.85), stagger 40–70ms, bloom 900–1200ms,
  ambient loops 6–10s.
